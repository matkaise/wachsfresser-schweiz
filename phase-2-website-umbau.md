# Phase 2: Website-Umbau zum Wachsfresser-Shop

Stand: 2026-05-03  
Ziel: Das bestehende Mockup inhaltlich von einer normalen Betonkerzen-Website zu einem korrekten, vertrauenswuerdigen Wachsfresser-Shop aus Salmsach/Thurgau umbauen.

## 1. Grundprinzip fuer Phase 2

Wir passen die Website Schritt fuer Schritt an. Vor jeder Seite wird zuerst ein kurzer Fragenkatalog beantwortet. Erst danach werden Texte, Produktdaten und SEO-Felder angepasst.

Wichtig:

- Keine erfundenen Produkteigenschaften.
- Keine falschen Sicherheitsversprechen.
- Keine unklaren Nachhaltigkeitsclaims.
- Keine rechtlichen Aussagen, die nicht belastbar sind.
- Keine normalen Kerzen verkaufen, wenn eigentlich Wachsfresser gemeint sind.
- Sojawachs nur dort nennen, wo es fachlich stimmt: Startfuellung, Nachfuellung oder Produktbestandteil.

Feste Produktnotiz vom 2026-05-05:

- Der grosse Wachsfresser ist nur fuer den Aussenbereich gedacht.
- Die Brenndauer ist noch offen und muss durch einen Testlauf validiert werden.
